# AgentStage 功能清单

## 模块1：应用基础

| 功能编号 | 功能名称 | 功能描述 | 优先级 | 备注 |
|---------|---------|---------|--------|------|
| APP-01 | Windows 安装包构建 | 提供 `.msi` 或 `.exe` 安装包，支持一键安装与卸载 | P1 | 最终交付物，开发阶段先用便携版调试 |
| APP-02 | 应用启动与初始化 | 启动应用后加载本地数据，展示主窗口 | P0 | 首次启动引导用户创建首个 Agent |
| APP-03 | 本地数据持久化 | 使用本地数据库（如 SQLite）存储会话、消息、Agent 配置、用户设置 | P0 | 数据存储在用户目录下 |
| APP-04 | 数据备份与恢复 | 支持导出/导入应用数据，防止数据丢失 | P1 | 导出为压缩包或 JSON |
| APP-05 | 自动更新检测 | 应用启动时检测新版本，提示用户更新 | P2 | 可配置是否自动检查 |

## 模块2：Agent 管理

| 功能编号 | 功能名称 | 功能描述 | 优先级 | 备注 |
|---------|---------|---------|--------|------|
| AGT-01 | 创建 Agent | 用户创建一个新的 AI 角色，配置名称、头像、详细人设、简易人设、模型参数 | P0 | 模型必须支持 Function Calling，否则配置时报错 |
| AGT-02 | 编辑 Agent | 修改已创建 Agent 的角色信息、模型配置 | P0 | 编辑后立即全局生效，所有现有会话的 Prompt 使用新人设 |
| AGT-03 | 删除 Agent | 删除不再需要的 Agent 角色 | P0 | 删除前确认，可选择保留聊天记录 |
| AGT-04 | Agent 列表展示 | 侧边栏或独立页面展示所有已创建的 Agent，支持搜索 | P0 | 卡片或列表视图 |
| AGT-05 | 模型 API 配置 | 为每个 Agent 配置调用的 LLM 服务：选择模型、填写 API Key、Base URL、温度、Max Tokens 等 | P0 | 支持 OpenAI 兼容格式；配置时检测是否支持 Tool Calling |
| AGT-06 | API 连通性测试 | 配置完成后可发送测试请求验证 API 可用性 | P0 | 显示延迟和模型响应 |
| AGT-07 | Agent 头像与资料卡 | 支持上传/选择头像，查看 Agent 详细资料 | P1 | 资料卡展示详细人设和模型信息 |
| AGT-08 | 双人设配置 | 每个 Agent 独立维护「详细人设」（自身 System Prompt）和「简易人设」（给其他 Agent 看的简介），均支持用户编辑 | P0 | 是 Prompt 拼接的核心数据来源 |

## 模块3：会话管理

| 功能编号 | 功能名称 | 功能描述 | 优先级 | 备注 |
|---------|---------|---------|--------|------|
| SES-01 | 创建 1对1 会话 | 选择一个 Agent 创建私聊会话 | P0 | 一个 Agent 可拥有多个独立会话；创建后双方互为"好友" |
| SES-02 | 创建群聊会话 | 选择多个 Agent 创建群聊，支持命名和设置群头像 | P0 | 群聊最少 2 个 Agent |
| SES-03 | 会话列表展示 | 左侧边栏展示所有会话（1对1 + 群聊），按最近活动时间排序 | P0 | 显示未读消息数、最后一条消息预览 |
| SES-04 | 会话置顶与删除 | 会话支持置顶、从列表中移除（聊天记录保留在归档列表） | P1 | 删除会话后聊天记录保留，可在"归档"列表查看；私聊/群聊关系不删除；再次创建会话时生成新 session |
| SES-05 | 会话设置 | 修改会话名称、头像，查看/管理当前会话中的 Agent 成员 | P1 | 群聊可增删成员 |
| SES-06 | 会话搜索 | 按会话名称、参与者名称搜索会话 | P1 | 实时搜索 |
| SES-07 | 群聊禁言开关 | 每个群聊独立提供禁言开关，开启后该群聊不再自动触发任何 Agent 调用 | P0 | 默认开启（禁言），关闭后进入自动互动模式 |

## 模块4：聊天核心

| 功能编号 | 功能名称 | 功能描述 | 优先级 | 备注 |
|---------|---------|---------|--------|------|
| CHAT-01 | 用户发送消息 | 用户在输入框输入文本并发送，消息展示在聊天区域 | P0 | 支持 Enter 发送，Shift+Enter 换行 |
| CHAT-02 | Agent 回复消息 | Agent 接收上下文后调用 LLM API 生成回复 | P0 | 需要 loading 状态，支持停止生成 |
| CHAT-03 | 消息气泡展示 | 按发送者区分展示消息气泡，支持时间戳、头像 | P0 | 类似微信/QQ 的聊天气泡 |
| CHAT-04 | 聊天记录滚动与加载 | 聊天区域支持滚动查看历史消息，支持跳转到最新消息 | P0 | 首次加载最近 N 条，向上滚动加载更多 |
| CHAT-05 | 群聊 Agent 自动触发 | 群聊禁言关闭后，任何角色发送消息会自动触发群聊中其它 Agent 的调用；群聊消息达到上限后强制停止 | P0 | 触发后各 Agent 受全局最小间隔控制，积压消息批量处理 |
| CHAT-06 | 用户介入 Agent 对话 | 用户在 Agent 自动对话过程中可随时发送消息参与 | P0 | 用户消息进入上下文，正常触发其它 Agent |
| CHAT-07 | 消息复制与重新生成 | 支持复制消息内容，对 Agent 消息支持"重新生成" | P1 | 重新生成替换原消息或插入新消息 |
| CHAT-08 | 消息引用/回复 | 支持引用某条消息进行针对性回复 | P1 | 长按或右键菜单 |
| CHAT-09 | 聊天上下文管理 | 支持查看当前会话的系统提示词拼接逻辑，支持清空上下文 | P1 | 技术用户可查看原始 Prompt |
| CHAT-10 | send_message Tool | 为 Agent 提供 Function Calling 工具 `send_message`，参数含目标类型、目标 ID、内容，调用成功后不返回结果给 Agent | P0 | 不支持 Tool Calling 的模型无法配置 |
| CHAT-11 | 私聊自动触发 | 私聊中任何角色（用户或 Agent）发送消息后，触发接收方 Agent 的调用；私聊消息达到上限后强制停止 | P0 | 两个 Agent 私聊时受全局最小间隔控制，避免高频循环 |
| CHAT-12 | 可见消息历史维护 | 为每个 Agent 独立维护其可见的全部消息历史，按「私聊对象」和「群聊」分组 | P0 | Prompt 拼接时按此结构注入 |
| CHAT-13 | 全局最小触发间隔 | 每个 Agent 拥有全局最小触发间隔（默认 30s），间隔内积压的所有新消息一次性组装调用 | P0 | 适用于所有私聊和群聊触发场景 |
| CHAT-14 | 消息上限配置 | 私聊和群聊分别可配置 Agent 消息条数上限（不含玩家消息），达到上限后强制停止触发；默认开启，支持关闭 | P0 | 私聊和群聊的上限数值独立可配 |

## 模块5：用户角色（P2 优先级）

| 功能编号 | 功能名称 | 功能描述 | 优先级 | 备注 |
|---------|---------|---------|--------|------|
| USR-01 | 用户人设配置 | 用户可创建并管理自己的人设（名称 + 简介 txt） | P2 | 可创建多个人设 |
| USR-02 | 会话中选择用户身份 | 在每个会话中，用户选择以"普通用户"或"某人设"参与 | P2 | 默认普通用户 |
| USR-03 | 人设同步给 Agent | 当用户以某人设参与会话时，将该人设信息注入该会话所有 Agent 的 System Prompt | P2 | 让 Agent 知道"用户是谁" |
| USR-04 | 用户头像与昵称 | 配置默认用户头像和昵称 | P2 | 普通用户模式下也生效 |

## 模块6：系统设置

| 功能编号 | 功能名称 | 功能描述 | 优先级 | 备注 |
|---------|---------|---------|--------|------|
| SET-01 | 通用设置 | 设置语言、主题（明亮/暗黑）、字体大小 | P1 | 默认跟随系统 |

## 优先级定义

| 优先级 | 含义 | 标识 |
|-------|------|------|
| P0 | MVP 必须，核心功能 — 缺少则产品不可用 | 🔴 |
| P1 | 重要增强，首版应有 — 缺少影响体验 | 🟡 |

## 实现顺序建议

按用户要求，开发优先级如下：

1. **阶段一：Agent 配置 + UI**
   - 完成 Agent 的创建、编辑、双人设配置、模型 API 配置、强制 Tool Calling 检测、Agent 列表 UI
   - 完成应用基础框架和本地数据存储

2. **阶段二：用户与 Agent 的 1对1 对话**
   - 完成私聊会话创建、消息收发、好友关系建立
   - 完成 Prompt 拼接逻辑（含好友/群友筛选）
   - 完成 `send_message` Tool 接入
   - 完成全局最小触发间隔、私聊消息上限

3. **阶段三：群聊**
   - 完成群聊创建、禁言开关
   - 完成群聊中的多 Agent 自动触发逻辑
   - 完成群聊消息上限、简易人设同步、可见消息历史维护
